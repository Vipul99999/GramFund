# GramFund Frontend (Next.js + React + TailwindCSS)

Production-ready frontend with:
- Secure cookie-based auth context, refresh flow, logout-all support, role gates
- Centralized typed API client (timeouts, retries, CSRF headers, error taxonomy)
- Offline-first UX panel (queue/conflicts/sync controls + safe mode)
- Audit timeline view and operator workflow modules
- WCAG-focused states, skip link, ARIA labels, live error regions
- Lazy loading, modular components, and design primitives
- i18n text keys (EN/HI), SEO pages, sitemap/robots
- PWA manifest, service worker caching, and branded logo/icon assets

## Run
```bash
npm install
npm run dev
```
